## JPay

See [the JPay workskin AO3 tutorial](https://archiveofourown.org/works/91566821/).
If you want to be able to save your work locally, you can download [playground.html](playground.html) and [jpay.css](jpay.css), and then make your edits in playground.html while also having it open in a browser.
I recommend using an IDE program like [Visual Studio Code](https://code.visualstudio.com/) to edit the file, since it will be able to help you out with some colors and formatting to make sure you're filling out the template correctly.
